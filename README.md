# Gerenciador de Contratos

Aplicação web desenvolvida em **React** para auxiliar no controle, na gestão e na fiscalização de contratos administrativos, especialmente aqueles submetidos à **Lei Federal nº 14.133/2021 (Nova Lei de Licitações)**.

## 🚀 Demonstração

A aplicação está disponível online:

**[Acessar o sistema](https://gestaodecontratos--joaoguilherm142.replit.app/contratos)**

## 🛠️ Tecnologias

* React
* Vite
* React Router
* JavaScript
* Oxlint

## 📌 Funcionalidades

O projeto está em desenvolvimento e tem como objetivo centralizar informações relacionadas à gestão de contratos administrativos.

Entre as funcionalidades atualmente desenvolvidas estão recursos para:

* Cadastro e gerenciamento de contratos;
* Cadastro e relacionamento de fornecedores;
* Consulta das informações dos contratos;
* Organização dos dados para acompanhamento e fiscalização.

## 💻 Instalação

Clone o repositório:

```bash
git clone https://github.com/JoaoGuilhermeTP/gestao_de_contratos.git
```

Entre na pasta do projeto:

```bash
cd gestao_de_contratos
```

Instale as dependências:

```bash
npm install
```

Execute o projeto em ambiente de desenvolvimento:

```bash
npm run dev
```

## 📦 Outros comandos

Gerar uma versão de produção:

```bash
npm run build
```

Executar o lint:

```bash
npm run lint
```

Visualizar a versão de produção:

```bash
npm run preview
```
